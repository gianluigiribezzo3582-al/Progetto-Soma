Handoff notes

  1. Design on a 390 × 844 frame (iPhone 14/15). Keep the status bar (0–47) and home indicator (810–844) free.
  2. Screens taller than 844 scroll. The screenshots below show the full scroll height; the tab bar always stays at the bottom of the visible area.
  3. Charts in Waves and in the report are drawn from data in code: design their style (colours, stroke, labels, spacing) rather than the exact values.
  4. Text in the screens is real copy from the app. If you change wording, send the new text with the graphics.
  5. Replacement images: keep the same file names listed above and the app picks them up without code changes.
  6. Colours, fonts, radii and spacing come from a single list of variables, so a new palette or type scale can be applied everywhere at once.

Coordinates in the screen tables are measured from the top-left corner of the frame (X, Y) on the full scrolled screen. Padding is listed top, right, bottom, left. Colours with a percentage are transparent.
